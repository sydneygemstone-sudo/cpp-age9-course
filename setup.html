🛠 我的电脑变成编程实验室 1 / 14
出发

今天，你要把自己的电脑
改造成一间编程实验室 🚀

全部步骤你自己就能完成。老师不用碰你的电脑。

你要装两样东西

  1. 一个写代码的本子 —— 叫 VS Code。它长得像记事本，但会帮你把代码涂上颜色、还会提醒你写错了。
  2. 一个翻译官 —— 叫编译器。你写的是英文单词，电脑只懂 0 和 1，翻译官负责把你的代码翻译给电脑听。
✅ 慢慢来，不着急
这份指南一共 14 页，每页只做一件事。做完一页，点右下角「下一步 →」。中间要是卡住了，把那一页拍给老师看就行。
💡 电脑上会弹出很多英文，别怕——你只要认识几个词就够用了。每页最下面我都会教你 2、3 个。
今天的第一个词 code ＝ 代码 install ＝ 安装
第 1 步

先认识一个工具：访达

访达（Finder）就是管理电脑里所有文件的地方，像一个大柜子。

  1. 看屏幕最下面那排图标（叫「程序坞」）。
  2. 最左边有一个蓝色的、笑着的方脸，那就是访达。
  3. 点它一下，会打开一个白色窗口。
  4. 左边一栏里找到「下载」和「应用程序」——等一下我们要用到这两个。
✅ 做完了吗
你能看到一个窗口，左边有「下载」「应用程序」这两行字。能，就继续。
认一认 Finder ＝ 访达 file ＝ 文件 folder ＝ 文件夹
第 2 步

下载写代码的本子

它的名字叫 VS Code，是免费的。

  1. 打开浏览器（Safari 或 Chrome 都行）。
  2. 在最上面的地址栏里，一个字一个字地输入：
    code.visualstudio.com
    然后按回车键。
  3. 页面上有一个大大的蓝色按钮，写着 Download for macOS（意思是"下载 Mac 版"）。点它。
  4. 如果它问你要哪个版本，选写着 Apple Silicon 的那个。
  5. 浏览器右上角会出现一个小箭头在转圈——它正在下载，等它转完。
⚠️ 别点错
页面上其他写着 Download 的按钮先别点。只点最大的那个蓝色按钮。
按钮上的词 download ＝ 下载 for ＝ 给…用的
第 3 步

把它搬进「应用程序」

下载下来的东西住在「下载」文件夹里，要把它搬到正式的家。

  1. 回到访达窗口，点左边的「下载」。
  2. 找到一个蓝色的图标，名字里有 Visual Studio Code。
  3. 如果它是一个压缩包（图标像个盒子），双击它，旁边就会解压出真正的程序。
  4. 按住那个蓝色图标不放，拖到左边那一栏的「应用程序」上面，松手。
  5. 它就搬好家了。
✅ 做完了吗
点左边的「应用程序」，能在里面找到 Visual Studio Code。找到了就继续。
认一认 Applications ＝ 应用程序 Downloads ＝ 下载
第 4 步

第一次打开它

电脑第一次见到新程序会有点紧张，会问你一句话。

  1. 在「应用程序」里双击 Visual Studio Code。
  2. 可能会弹出一个框，问你「确定要打开吗？」——点「打开」。
  3. 等几秒，一个深色的大窗口就出来了。这就是你以后写代码的地方。
⚠️ 如果它说"无法打开，因为无法验证开发者"
别慌，这是电脑太小心了。这时候叫老师或爸爸妈妈来一下，需要在「系统设置 → 隐私与安全性」里点一个「仍要打开」的按钮。
弹窗上的词 open ＝ 打开 cancel ＝ 取消
第 5 步

把它变成中文界面

现在它满屏是英文。我们先让它说中文，等你熟了再换回英文。

  1. 看 VS Code 窗口最左边那一竖排图标。
  2. 找到四个小方块的那个图标（第五个，像积木），点一下。
  3. 上面出现一个搜索框，输入：Chinese
  4. 第一个结果写着 Chinese (Simplified) (简体中文)，点它右边的蓝色 Install 按钮。
  5. 装完后，右下角会跳出一个小框问你要不要重启，点 Restart（重新启动）。
  6. 窗口自己关掉再打开——菜单全变成中文了！🎉
你刚刚用到的词 install ＝ 安装 restart ＝ 重新启动 extension ＝ 扩展（小插件）
第 6 步

认识第二个工具：终端

终端（Terminal）是一个只能打字、不能点的黑框框。程序员用它给电脑直接下命令。

  1. 在 VS Code 里，点最上面菜单栏的「终端」。
  2. 再点「新建终端」。
  3. 窗口下半部分裂开一块，出现一些字，最后有一个方块在闪 —— 它在等你打字。
✅ 试一下
输入 date 然后按回车。它会告诉你现在几点。
这就是你给电脑下的第一条命令 —— 和课件里给机器人发命令是一回事！
认一认 terminal ＝ 终端 new ＝ 新建 date ＝ 日期
第 7 步

请翻译官来上班

这一步要装编译器。它有点大，要下载很久很久。

  1. 在刚才的终端里，一个字一个字输入下面这行（中间的两个横杠不能少）：
xcode-select --install
  1. 按回车。
  2. 屏幕上会弹出一个窗口，问你要不要安装工具。点「安装」。
  3. 它会让你同意一份很长的协议，点「同意」。
  4. 然后……开始漫长的等待。
⚠️ 可能会问你要密码
如果弹出一个要输入密码的框，叫老师或爸爸妈妈来输，那是电脑管理员的密码，你不用知道。
这行命令的意思 select ＝ 选择 install ＝ 安装
第 8 步

等待时间 ☕️

这个下载有好几个 GB，可能要等 20 分钟到 1 个小时，取决于你家网快不快。

⚠️ 三件不要做的事
  • 不要关掉那个进度窗口
  • 不要合上电脑盖子（会睡着，下载就停了）
  • 不要拔电源

等待的时候可以做什么

  • 去玩一遍课件里的第 1 课，把「能量盒」那一关再走一次
  • 把这一页往后翻，先看看等会儿要写的代码长什么样
  • 喝口水，休息一下眼睛 👀
💡 装好之后进度窗口会自己消失，或者显示「安装完成」。看到了就翻到下一页验收。
第 9 步

检查翻译官来了没有

我们让他自报家门。

  1. 回到终端，输入：
g++ --version
  1. 按回车。

如果看到这样几行字（数字不一样没关系）

Apple clang version 21.0.0
Target: arm64-apple-darwin27.0.0
🎉 成功了！
翻译官已经在你的电脑里上班了。g++ 就是他的名字。
⚠️ 如果它说 command not found
意思是「找不到这个命令」，说明第 7 步还没装完。回到第 7 步再来一次。
认一认 version ＝ 版本 command not found ＝ 找不到这个命令
第 10 步

给自己造一个工作间

代码要有地方住。我们建一个专门的文件夹。

  1. 在终端里输入这一行，按回车：
mkdir -p ~/我的C++/第1课
  1. 再输入这一行，按回车：
cd ~/我的C++/第1课
  1. 在 VS Code 里点「文件 → 打开文件夹」，找到你刚建的「我的C++」，打开它。
✅ 做完了吗
VS Code 左边出现了「我的C++」这个文件夹的名字。出现了就继续。
命令的意思 mkdir ＝ 建一个文件夹 cd ＝ 走进某个文件夹
第 11 步

写下你的第一个程序 ✍️

还记得课上机器人的能量盒吗？我们现在真的把它写出来。

  1. 在 VS Code 左边「第1课」文件夹上点右键 →「新建文件」。
  2. 给它起名字：energy.cpp（后面的 .cpp 一定要有）。
  3. 把下面这几行一个字一个字敲进去（不要复制粘贴，敲一遍你才会记住）：
#include <iostream>

int main() {
    int energy = 3;
    energy = energy + 4;
    energy = energy - 1;
    std::cout << energy;
    return 0;
}
  1. 按 ⌘+S 保存。
🤔 敲完先别急着跑。猜一猜：屏幕上会出现几？ 把你猜的数字记在心里。
代码里的词 int ＝ 整数 energy ＝ 能量 cout ＝ 喊出来（输出）
第 12 步

让翻译官翻译，让电脑跑起来 🏃

两条命令，一条翻译，一条运行。

  1. 在终端里输入这一行（翻译），按回车：
g++ -std=c++17 energy.cpp -o energy
  1. 如果什么都没显示 —— 那就是成功了！翻译官不出声就是没挑出毛病。
  2. 再输入这一行（运行），按回车：
./energy
🎉 屏幕上出现 6 了吗？
和你刚才猜的一样吗？和课件里机器人的能量一样吗？
三个 6 —— 你手算的、课件演的、你自己电脑跑出来的。 你已经是真的在写 C++ 了。
⚠️ 如果冒出一堆红字
那是翻译官在告诉你哪里写错了。看红字里的数字（比如 line 6），那就是出问题的行号，回去检查那一行是不是少了个分号 ;。
命令的意思 -o ＝ 输出成… error ＝ 错误 line ＝ 行
第 13 步

作业：让它变成 10 🎯

课上你在屏幕里把能量凑到过 10。现在在你自己的电脑上再做一次。

要求

  1. 打开 energy.cpp。
  2. 只改一个数字，让程序跑出来正好是 10。
  3. 改之前先在纸上算一遍，写下你觉得会是几。
  4. 然后重新翻译、重新运行，看看和你算的一样不一样。
g++ -std=c++17 energy.cpp -o energy
./energy

加分题（想挑战再做）

  • 在每一行下面都加一句 std::cout << energy;，看看能不能把 3、7、6 全都喊出来。
  • 试试故意删掉一个分号，看翻译官会说什么。把错误弄出来也是一种本事 —— 你要认识他生气的样子。
📝 下次上课带来：你改的那个数字是几？为什么改它？
完成

你的实验室建好了 🎉

从今天起，你的电脑不只是能看视频的电脑了。

✅ 下次课之前，确认这三件事都是好的
  1. VS Code 能打开，菜单是中文的
  2. 终端里输入 g++ --version 有回应
  3. energy.cpp 还在「我的C++/第1课」文件夹里
