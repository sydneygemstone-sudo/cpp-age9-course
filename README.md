# 九岁儿童 C++ 互动课程 · 一期纵向样片

## 这是什么

这是一套面向九岁儿童的**一对一、诊断自适应、可视化 C++ 编程实验室**：孩子在浏览器里通过"先预测 → 再运行 → 再解释"的循环，操纵机器人、能量条和智能舱门来学习顺序执行、变量与条件分支；老师在教师端观察证据、调整支架、生成家长报告；关键节点用真实的 g++ 远程编译来验证学习的真实性。一期只交付三段纵向样片——试听/诊断课、第 1 课《机器人能量站》、第 2 课《智能舱门》——目标是证明整条"教学 → 诊断 → 承接 → 真实编译 → 报告"链路可用，而不是做十二节半成品页面。

## 怎么运行

**不需要安装任何东西，不需要构建，不需要命令行。**

1. 在电脑上找到本项目文件夹；
2. 双击 `index.html`，用桌面 Chrome（或其他 Chromium 内核浏览器）打开——这就是儿童端；
3. 教师端入口在儿童端首页右下角的小字「教师入口」，或直接双击 `teacher.html` 打开。

整站是纯静态页面，直接以 `file://` 方式运行，无需本地服务器。

**关于联网**：课堂教学（动画、单步执行、预测、证据记录、报告）全部离线可用。只有「真实 C++ 验证」这一个按钮需要联网——它把孩子的代码发给公共编译服务，用真实的 g++ 编译运行。断网时该功能自动降级为**概念演示**，界面会明确显示「⚠️ 概念演示——真实编译暂不可用」，绝不会伪装成"验证成功"。

## 教师入口

- 入口：儿童端首页右下角小字「教师入口」，或直接打开 `teacher.html`；
- 默认 PIN：**8888**（可在教师端内修改，修改后保存在本机浏览器中）；
- 教师端功能：实时面板（当前活动/支架/证据/提示使用）、六张教师卡、证据修订、路径建议与人工覆盖、家长报告的生成/编辑/确认/打印、数据导出与删除。

详细操作请读 `docs/教师手册.md`——教师无需阅读任何代码即可授课。

## 数据存在哪里

- 所有数据（会话、进度、作品卡、证据、教师笔记、报告草稿）只保存在**本机浏览器的 localStorage** 中，键名 `cpplab_session_v1`；不上传任何服务器，不建立学生账户；
- 只记录昵称，不采集真实姓名、学校、生日、音频或连续键盘录像；
- **导出**：教师端提供「导出 JSON」，把完整会话下载为一个 JSON 文件备份（换电脑前请先导出）；
- **删除**：教师端提供「删除会话」，清空本机全部课程数据；清除浏览器站点数据有同样效果；
- 注意：数据跟随"这台电脑的这个浏览器"。换浏览器、换电脑或使用隐私/无痕模式都不会看到原有进度。

## 故障与降级

| 状况 | 系统行为 | 你需要做什么 |
|---|---|---|
| 断网 | 「真实 C++ 验证」返回离线状态，界面显示「概念演示——真实编译暂不可用」，其余教学功能照常 | 照常上课，课后联网再补一次真实验证 |
| 编译超时（15 秒） | 明确提示超时，不显示虚假结果 | 稍后重试；连续失败按断网处理 |
| 编译服务报错 | 显示儿童化的错误解释（教师端可展开原始 stderr） | 按提示引导孩子检查对应行 |
| 页面刷新 / 误关浏览器 | 重新打开 `index.html` 后从 localStorage 自动恢复会话与进度 | 点「继续我的任务」 |
| 孩子操作失败 / 想重来 | 每个活动都有「重置」，只重置当前活动，不丢课程进度 | 放心点重置 |

## 一期范围与已知边界

一期交付物与验收标准见方案定稿 §十二（以及本仓库 `docs/验收对照.md`）：试听闭环、第 1/2 课连续教学、内容驱动引擎、编译适配器、证据与报告、教师端，均为一期范围。

一期**明确不做**（方案 §十八）：第 3–12 课完整页面（只有地图与占位元数据）；浏览器内完整 Clang；通用 C++ AST 解析器；指针、模板或复杂面向对象；语音 AI 与开放式聊天；排行榜与多人协作；云账号系统；付费；部署发布；全仓重构。LLM 助教一期默认关闭，仅保留可插拔接口——没有网络、没有 AI 时，课程全流程照常可用。

已知边界：真实编译依赖公共编译服务（联网 + 对方可用），每次调用间隔至少 1 秒并有 15 秒超时；自由编辑模式（A 档）的任意代码可以真实编译运行，但不做逐行可视化，界面会标注「控制台模式」；数据仅存本机，一期不提供跨设备同步，换机前请用「导出 JSON」留存备份。
