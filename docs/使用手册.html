📖 这是什么

一套面向九岁孩子的一对一、可视化 C++ 编程课。孩子在浏览器里通过"先预测 → 再运行 → 再解释"的循环学编程；你在教师端看他的证据、调难度、生成家长报告；关键节点会把代码发给真正的 C++ 编译器跑一遍，证明学的是真东西。

一期做了三段完整内容：试听/诊断课、第 1 课《机器人能量站》（顺序执行、变量、赋值）、第 2 课《智能舱门》（条件判断）。第 3–12 课只有课程地图，还没做。

✅ 现在的上课形态 你的 Mac 起服务器 → 学生用他自己的电脑连过来上课 → 你在自己 Mac 上开教师端看他、控制他的难度。两台机器要在同一个 WiFi。

🚀 每次上课怎么开

1起服务器（你的 Mac，终端里跑）

cd ~/cpp-course
node tools/make-seed.js --nickname "孩子的昵称" > server/seed.json
node server/server.js --port 8099 --seed server/seed.json --fresh
⚠️ 关于 --fresh：开新课加，课中重启不加 开一堂新课 → 加 --fresh。不加的话，上一堂课（或课前彩排）留下的会话会被沿用，你新设的昵称和难度档会被忽略。
课上中途误关了终端、要重开 → 不要加。去掉它才能接着上一轮，孩子的进度不丢。
✅ 启动后先看这几行，再把链接发给学生 
本次课堂使用的会话：
  来源     种子文件 server/seed.json
  昵称     孩子的昵称
  档位     A
  主题     robot
昵称和档位对不上就别发链接——多半是漏了 --fresh，按屏幕提示重来。

2把链接给学生

http://<你的电脑IP>:8099/index.html

服务器启动时会自己把地址打出来。Mac 的 IP 可能变，每次以启动时打印的为准。学生用 Chrome 打开（课件只保证 Chromium 内核，别用 Safari）。

3你自己开教师端

http://localhost:8099/teacher.html

PIN 8888（可在教师端里改，改完只存在你这台机器）。这页别投屏给孩子，上面有难度档和判定。

⚠️ 第一次跑会弹一个系统框 macOS 会问"是否允许 node 接受传入网络连接"，点允许，否则学生连不上。

🎛 课中操作

你想做什么怎么做注意
调难度档 教师端「控制区」→ 上调/下调一档 只在两个活动之间调（等孩子点完「下一个任务！」）。孩子做到一半时调，屏幕会留着旧题面而引擎已换档，数字对不上
放最后一级提示 教师端对应活动 → 解锁 H5 H5 几乎等于给半个答案，孩子自己按「求提示」只能拿到前四级
随手记一笔 教师端「教师笔记」卡 课后写家长报告时用得上
改判定 教师端证据流 → 修订 系统自动评分最高到 2 级；第 3 级只能你手动给，依据是孩子能否解释和迁移
让孩子重做某一关 教师端 → 重置该活动 只重置那一关，不影响课程进度
🚫 课上不要碰的两个东西 1. 教师端的「删除会话」——跨机模式下它是坏的：孩子那边会被清空，服务器上的旧数据却留着，之后孩子端上传会一直被拒。
2. 不要同时开两个儿童端（比如学生开一个、你这边又开一个）。两个都会往服务器写整份会话，会互相把进度整包覆盖，孩子做过的活动可能直接消失。儿童端全程只留学生那一个。

📦 课后

  1. 确认作品卡存了——每课最后一个创作关要让孩子点「💾 保存我的作品卡」。第 2 课开场会读第 1 课的作品卡续写剧情，跳过了下节课会接不上。
  2. 补记解释质量——最后一关"讲给机器人听"系统默认记"未打分"，等你在教师端判。
  3. 生成家长报告——教师端「报告区」生成草稿 → 逐条编辑 → 确认 → 打印/导出。
  4. 导出会话 JSON——换电脑或想留档前先导出。
⚠️ 家长报告的草稿要改了再发 自动草稿有三处会让家长看糊涂：标题写的是「一、试听概况」「试听日期」（正课不是试听）；「本次学到的内容」整段写成「既有基础，无需现场教学」（意思正好说反）；引用的任务描述是从课件截断的半句话。草稿只是帮你省打字，发出去前一定过一遍。
报告正文本身不会出现难度档（E/S/A）和分数，这是产品红线——你自己编辑时也别写。
✅ 数据存在哪 孩子的进度存在他那台电脑的浏览器里，同时同步一份到你 Mac 的 ~/cpp-course/server/data/（每次上传都留快照，保最近 50 份）。不上传任何外部服务器，只记昵称，不采集真实姓名。

🔌 出问题怎么办

现象实际发生了什么你怎么做
学生打不开链接连不上你的服务器 确认同一 WiFi；确认那个"允许 node 接受连接"点了允许；用启动时打印的那个 IP
学生看到的是要求填昵称、选世界的页面课前种子没送到他那边 停掉服务器，加 --fresh 重跑第 1 步，让他刷新页面
服务器中途挂了孩子照常上课，进度存在他本机，一点不丢 不用慌。你的教师端会看不到实时状态；要调档就去他电脑上开一下 teacher.html（10 秒）。重启服务器时不要加 --fresh
点「真实C++验证」显示「⚠️ 概念演示」断网或公共编译服务不可用。系统绝不会假装成功 照实告诉孩子，照常上课。作品卡照常保存，只是没盖章，下次联网补验证一次即可
孩子想重玩前面的关卡整课完成后重进只会停在最后一关 课上别答应。真要重来：先「导出会话 JSON」留档，再关服务器、删掉 ~/cpp-course/server/data/
端口被占用（EADDRINUSE）8099 被别的东西占了，或上一个服务器没退干净 lsof -nP -tiTCP:8099 -sTCP:LISTEN | xargs kill -9 然后重跑

🔧 维护与开发

改完东西之后

# 1. 跑测试（7 套必须全绿）
cd ~/cpp-course
for f in js/tests/test-*.js; do node "$f"; done

# 2. 跑闭环 QA（真实浏览器点完第 1 课 8 关，约 2 分钟）
node server/server.js --port 8099 --seed server/seed.json --fresh &
node qa/cdp-lesson1.mjs

# 3. 提交
git add -A && git commit -m "说明改了什么"

同步到 MSI

rsync -a --delete --no-perms --no-owner --no-group \
  --exclude 'server/data' --exclude 'server/seed.json' --exclude 'qa/shots' \
  ~/cpp-course/ \
  "<备份机挂载点>/…/cpp-age9-course/active/source-tree/"

# 必做：清掉 macOS 写到 SMB 上的元数据文件，否则会污染 .git
find "<备份机挂载点>/…/active/source-tree" -name "._*" -type f -delete
⚠️ 这一步的坑 往 SMB 同步会产生几百个 ._ 开头的文件，其中 ._main、._tags 会跑进 .git/refs 里，让 git 报 badRefName。每次同步完都要跑上面那条 find 删除。

MSI 上跑 codex worker

ssh <用户名>@<备份机的 tailscale 地址>

这台备份机局域网 IP 的 22 端口不通、445 通——所以 SMB 挂载能用不代表 ssh 能用同一个地址，要走 tailscale。地址用 tailscale status 查。具体地址见本机桌面上的手册副本。

📌 还没做的事

  • 教师手册（docs/教师手册.md）还是同机时代写的——里面"双击 index.html""教师端开第二个窗口""在教师端创建会话"这些说法在现在的跨机模式下都不成立。核对出 31 项不一致，等实际上过一次课再改更准。
  • 教师端「删除会话」在跨机下是坏的，暂时绕开（见上面红框）。
  • 家长报告生成器没改，只是把要改的地方写进了说明。
  • 第 3–12 课只有课程地图，没有实际内容。
