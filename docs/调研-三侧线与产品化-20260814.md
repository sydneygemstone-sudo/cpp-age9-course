## 侧线 1：Mac 操作系统基础流程（账户 → 浏览器 → IDE 部署）

**定位**：不是独立课程，做成每课前 5–10 分钟的「登机仪式」+ 一本图文小手册，让孩子逐步接管自己的电脑。

**建议的阶梯**（每课解锁一格，和现有勋章体系挂钩）：
1. 开机登录自己的账户、认识 Dock/Finder/访达、连 Wi-Fi
2. 打开浏览器、输网址（连老师服务器 `http://<IP>:8099`）、建书签
3. 文件的概念：新建文件夹「我的代码」、保存/找到一个 `.cpp` 文件
4. 在线 IDE：godbolt.org 自己打开、自己贴代码、自己点编译（现有 app 已用它，天然衔接）
5. 本地 IDE 部署（第二学期再做）：装 VS Code → 中文语言包 → `xcode-select --install` 装 clang → 跑通第一个本地 hello world。**不建议**一上来装完整 Xcode（重、慢、界面吓人）。

**产品形态**：复用 `周六课前checklist.html` 的模式做一份《小队长登机手册》slide/卡片页，进度存进现有 state。

## 侧线 2：在家自学窗口（知识区/题库/小游戏）

agy 探针实测结果 ✅（6 站全部可访问）：

| 资源 | 判定 | 用法建议 |
|---|---|---|
| 洛谷 luogu.com.cn | 中文✅ 有新手入门题单，偏算法竞赛风 | **家庭练习主站**（家长陪同，只做入门题单前段） |
| Codingame | 游戏化但全英文、难度偏高 | 暂不用，二年级英语上来后再看 |

**关键发现**：中文、少儿向、游戏化的 C++ 自学资源是**市场空白**（中文游戏化平台基本都是 Scratch/Python）。所以「在家练习」最可靠的路是：
- **短期**：本课件 `file://` 方式 B 就是现成的家庭版——把每课的「家庭任务卡」（3 道复习小题 + 1 个改代码小实验）做进 app，家里双击即用，零网络依赖。
- **中期**：洛谷入门题单（家长陪同）+ godbolt 自由实验。
- agy 二发探针补查 ✅（2026-08-14 晚）：
  - **一本通 OJ**（ybt.ssoier.cn）：可访问，但界面简陋、题目硬核偏应试——零基础不上，留作二年级后备选。
  - **B 站少儿 C++ 视频课**：判定「非常适合」入门建概念（免费、视听结合）。探针报了《李炎恢 C++信奥启蒙》《小学生C++趣味编程》等系列名，**具体课名待人工点开确认**（flash 模型可能编名字），方向可信：B 站中文视频课是家庭自学的好补充。
  - **编程猫**：有自研 Kitten C++ 编辑器与信奥体系课，门槛低但商业付费——不急，先用自建家庭任务卡。
  - **双语术语资源**：Quizlet 编程术语闪卡、Code.org 汉化术语表可作参考；结合 Dean 的双语定案，更推荐**自建每课 5 词的「术语卡」**进家庭任务卡（compile/variable/output…），与课件同一套视觉。

## 侧线 3：沉浸感 / UI / 视觉呈现

**现状盘点**：主题词典 `js/engine/theme.js`（勘误：曾误写 js/ui/，实测在 engine/）三主题变体已在（robot 等）；问题是一屏元素过多、按钮分心、活动之间缺过渡仪式感。

**三个方案**：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A. 现有 app 加「剧场模式」（推荐）** | CSS/渲染层改造：一屏只呈现当前活动（slide 式翻页）、非当前按钮全部收进抽屉、活动切换加主题化过渡动画（火箭发射/机器人开门） | 改造面小，1936 断言与引擎资产全保留，最快见效 |
| B. 独立 slide 引擎 | 零依赖自建 reveal.js 式外壳，活动 iframe 嵌入 | 双份维护，同步层要穿透 iframe，性价比低 |
| C. 重写新产品 | 全新沉浸式课件 | 弃全部已验证资产，不做 |

**统一视觉风格（claude design 的切入点）**：先产出一份 **design tokens 规范**（色板/字号阶梯/间距/圆角/动效时长，按三主题各一组），加 **3 张样板页**（封面页/活动页/庆祝页）给 Dean 过目；拍板后再批量套用到全部活动。这就是「产品化打包」的地基——今后试听课、第 1/2/3 课、家庭任务卡全都长在同一套视觉系统上，天然就是可复用的课程产品。
